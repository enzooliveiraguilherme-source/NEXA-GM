# Resumo de aplicação: pendências em vermelho e nomes de apresentação

As áreas anteriormente neutras no resumo passam a vermelho, com a classe Não aplicado, incluindo aplicações com data futura, sem data e talhões sem registro da aplicação selecionada. Verde continua Aplicado e amarelo continua Em andamento. O mapa operacional anterior conserva suas regras. Enquanto os dados ainda carregam ou estão indisponíveis, o resumo continua neutro para não apresentar uma conclusão sem dados confirmados.

Os indicadores e a barra do resumo usam três classes. Aplicações elegíveis sem data passam a integrar o total; a indicação de área usa o título Área total. As áreas e os registros da tabela continuam sendo a fonte dos indicadores; não são criados lançamentos ou áreas artificiais para talhões sem registro da aplicação. A confirmação por data ou OK continua prevalecendo sobre início; início registrado continua amarelo.

Quando a seleção é uma gleba, o código resolve diretamente para esse nome, inclusive FE com todas as unidades selecionadas. Uma unidade específica continua tendo prioridade sobre a gleba; unidades não listadas usam o nome já cadastrado. Todos os nomes acima são exclusivamente de apresentação neste resumo, conforme instrução do usuário para manter o cadastro como está. Não há alteração de fazendas, permissões, operações, geometrias ou qualquer outro dado no banco.
